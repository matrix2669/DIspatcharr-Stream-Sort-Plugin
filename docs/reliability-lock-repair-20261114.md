# Reliability lock repair — local candidate

The operator reported four blocked uWSGI workers, including one process both holding and waiting on `/data/dispatcharr_stream_sort_reliability.json.lock`. Arcane auto-heal restarted Dispatcharr and it recovered. Installed version was reported as 0.3.7-beta.1. No Python call stack was captured.

The exact matching source baseline is dev commit `8d3afff3bdd0bc0dbc780f211065d81f4da75149`. In this baseline `_locked_cache` opens a new descriptor and takes blocking exclusive flock. Runtime event handling calls the stream resolver (normally ORM-backed) while holding the lock. An isolated resolver callback that records another event on the same path reproduces indefinite self-blocking. An RLock-only substitution reproduces lost nested writes: the outer stale snapshot overwrites the nested save. These establish reachable code defects, not the actual unrecorded live callback chain.

The bounded repair keeps one cache transaction and queues same-thread nested operations in invocation order after the current operation. Nested results explicitly mean queued, not persisted. Reset participates in that same ordering. A single acquisition budget covers local-thread and interprocess contention; failure does not write or clear history. Owner ORM work and filesystem operations are not bounded by the acquisition deadline, and this repair does not claim a total request-time guarantee. Data attribution, scoring, schema and provider behavior remain unchanged.

Implementation and independent Astra review are complete locally. No live operations, source publication, registry changes or deployment are authorized. The original operator evidence is retained separately in `/workspace/stream-sort-lock-evidence/operator-receipt.json`, without runtime data or credentials.

The first review found unsafe fork descriptor reuse/inherited commits and unnecessary writes for ignored events. Both were repaired and verified. Forked child cleanup cannot unlock the parent or close a newly reused descriptor, and inherited transactions cannot commit. Queue overflow aborts the transaction; at most 256 nested operations are admitted.
